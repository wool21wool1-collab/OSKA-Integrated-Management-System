# GitHub 배포 폴더

수정 완료 후 이 폴더에 최종 파일을 복사하여 GitHub에 업로드하세요.

## 업로드 방법
1. 수정이 완료되면 루트의 index.html, manifest.json, sw.js, assets/ 폴더를 이곳에 복사
2. 각 프로그램 폴더(quotation/, simple/ 등)의 index.html도 필요시 복사
3. GitHub 레포에 이 폴더 내용을 push

## 폴더 구조 (GitHub Pages용)
```
github/
├── index.html          ← 메인 포탈
├── manifest.json
├── sw.js
├── assets/
│   ├── 오스카CI_04LogoBLACK_1.png
│   ├── icon-192.png
│   └── icon-512.png
├── quotation/index.html
├── simple/index.html
├── deck/index.html
├── catalog/index.html
├── as/index.html
└── ask/index.html
```
